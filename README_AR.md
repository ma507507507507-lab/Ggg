# PNGTuber للأندرويد

نسخة أولية خفيفة: تعرض شخصيتك فوق التطبيقات، وتستخدم الميكروفون لتبديل صورة الفم بين ساكت/يتكلم.

## التشغيل
1. افتح المشروع في Android Studio.
2. استخدم Android SDK 35 وJDK 17.
3. Build > Build APK(s).
4. عند أول تشغيل اسمح للمايك و"الظهور فوق التطبيقات".

الصور الحالية مأخوذة من تصميم الشخصية الذي تم إنشاؤه في المحادثة، ومقسومة إلى `silent.png` و`talking.png`.
